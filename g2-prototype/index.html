4. 음성 인식 서버 설정

개인 Cloudflare Worker(Whisper AI) 서버를 연결해야 영어 받아쓰기가 동작합니다. 서버 주소는 자동으로 입력됩니다. 개인 접근 토큰은 직접 입력하거나 붙여 넣으세요. 토큰은 GitHub에 저장되지 않습니다.

토큰 입력칸을 누르기 어려우면 ‘클립보드에서 토큰 붙여넣기’를 사용하세요. iOS에서 클립보드 권한을 요청할 수 있습니다.

서버 주소가 Even Hub 앱의 네트워크 허용 목록에 등록돼 있어야 합니다. API 키는 이 화면에 입력하지 마세요.

본 앱은 원문과 미리 저장된 한국어 번역을 짝지어 보여줍니다. 새로운 번역을 자동 생성하지 않습니다.
